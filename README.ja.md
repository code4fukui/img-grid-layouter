# img-grid-layouter

複数の画像を単一のグリッドレイアウトに配置するウェブベースのツールです。印刷やコンタクトシートの作成に最適です。

## デモ

**[https://code4fukui.github.io/img-grid-layouter/](https://code4fukui.github.io/img-grid-layouter/)**

## 機能

*   **カスタマイズ可能なグリッド:** グリッドの寸法を最大4x4まで指定できます。
*   **柔軟なレイアウト:** ISO A/Bシリーズ、日本の写真サイズ、ハガキなど、あらかじめ定義された幅広い用紙サイズから選択でき、縦（ポートレート）と横（ランドスケープ）の向きを切り替えることができます。
*   **印刷対応の出力:** 印刷要件に合わせて出力解像度（DPI: 72、150、または300）を選択できます。
*   **ドラッグ＆ドロップインターフェース:** デスクトップから目的のグリッドセルにドラッグするだけで、簡単にJPEG画像を追加できます。
*   **アスペクト比を維持したスケーリング:** 画像は歪むことなくグリッドセルに収まるように自動的にスケーリングされ、中央に配置されます。
*   **即時ダウンロード:** ワンクリックで最終的な合成画像を単一のJPEGファイルとして生成し、ダウンロードできます。

## 使い方

1.  **レイアウトの設定:** ドロップダウンメニューから希望する用紙サイズ（デフォルト: B6）、DPI（デフォルト: 300）、グリッドの寸法（デフォルト: 4x2）を選択します。
2.  **向きの設定:** 縦または横のページレイアウトを選択します。
3.  **画像の追加:** 画面に表示されるプレースホルダーセルにJPEGファイルをドラッグ＆ドロップします。
4.  **画像の生成:** 「make!」ボタンをクリックします。
5.  **ダウンロード:** 生成された `grid-layout.jpg` ファイルがブラウザで自動的にダウンロードされます。

## 依存関係

このプロジェクトでは、以下の外部JavaScriptモジュールを使用しています:
*   [CSV.js](https://code4fukui.github.io/CSV/CSV.js): `papersize.csv` データのパース用。
*   [dataencoder](https://code4fukui.github.io/dataencoder/encodeData.js): 画像データのエンコード用。
*   [js.sabae.cc](https://js.sabae.cc/): `setDropFilesListener.js`、`waitFileRead.js`、`cr.js` などのユーティリティ関数用。

## データソース

*   [papersize.csv](papersize.csv) - ISO 216（AおよびBシリーズ）や一般的な日本のサイズを含む用紙寸法データ。Wikipediaから取得しています。
